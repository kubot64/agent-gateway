# Triage ラベル

スキルは 5 つの標準 triage ロールの名前で話す。このファイルは、そのロールとこのリポジトリの issue tracker で実際に使うラベル名との対応を示す。

| mattpocock/skills でのラベル | このリポジトリでのラベル | 意味                                       |
| ---------------------------- | ------------------------ | ------------------------------------------ |
| `needs-triage`               | `needs-triage`           | メンテナが評価する必要がある               |
| `needs-info`                 | `needs-info`             | 起票者からの追加情報を待っている           |
| `ready-for-agent`            | `ready-for-agent`        | 仕様が固まり、無人のエージェントが着手できる |
| `ready-for-human`            | `ready-for-human`        | 人間が実装する必要がある                   |
| `wontfix`                    | `wontfix`                | 対応しない                                 |

スキルがロールに言及したら（例:「AFK-ready の triage ラベルを付ける」）、この表の対応するラベル名を使う。

実際の語彙が変わったら「このリポジトリでのラベル」列を書き換える。
