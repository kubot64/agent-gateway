# agent-gateway

## Agent skills

### Issue tracker

issue と spec は GitHub Issues（`kubot64/agent-gateway`）で管理する。See `docs/agents/issue-tracker.md`.

### Triage labels

標準の 5 ロールをそのままのラベル名で使う（`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`）。See `docs/agents/triage-labels.md`.

### Domain docs

single-context。ルートの `GLOSSARY.md` と `docs/adr/` を使う。See `docs/agents/domain.md`.
